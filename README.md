# Estudos em Node.js  

Este repositório contém uma série de atividades e desafios de estudo sobre **Node.js** e **JavaScript**. Os conteúdos são divididos em pastas, cada uma com um conjunto de exercícios práticos.  

## 📂 Estrutura do Repositório  

O repositório está organizado da seguinte forma:  

```
📂 estudos-nodejs
├── 📂 atividades-funcoes
├── 📂 user-management-api
├── 📄 README.md 
```  

### 🔹 [Atividades de Funções e Arrays](./atividades-funcoes)  

Esta pasta contém atividades relacionadas ao uso de **funções** e **arrays** em JavaScript. Ela inclui operações matemáticas básicas e manipulação de arrays, como inverter um array ou gerar números pares. Cada atividade é modularizada em arquivos separados e utiliza a importação e exportação de funções.  

- **Atividade 1:** Operações matemáticas com módulos  
- **Atividade 2:** Inverter um array  
- **Atividade 3:** Gerar uma lista de números pares  

### 🔹 [API de Gerenciamento de Usuários](./user-management-api)  

Esta pasta contém uma **API RESTful** desenvolvida com **Node.js**, **Express** e **Sequelize**, focada no gerenciamento de usuários. A API permite **registro, autenticação e administração** de usuários, protegendo rotas com tokens JWT.  

Principais funcionalidades:  
- Registro e autenticação de usuários  
- Proteção de rotas com autenticação JWT  
- Listagem, atualização e remoção de usuários  
- Uso do **Sequelize** para gerenciamento do banco de dados
