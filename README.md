
# Estudos em Node.js

Este repositório contém uma série de atividades e desafios de estudo sobre **Node.js** e **JavaScript**. As atividades são divididas em pastas, cada uma com um conjunto de exercícios práticos.

## 📂 Estrutura do Repositório

O repositório está organizado da seguinte forma:

```
📂 estudos-nodejs
│-- 📂 atividades-funcoes
│-- 📄 README.md 
```

### 🔹 [Atividades de Funções e Arrays](./atividades-funcoes)

Esta pasta contém atividades relacionadas ao uso de **funções** e **arrays** em JavaScript. Ela inclui operações matemáticas básicas e manipulação de arrays, como inverter um array ou gerar números pares. Cada atividade é modularizada em arquivos separados e utiliza a importação e exportação de funções.

- **Atividade 1:** Operações matemáticas com módulos
- **Atividade 2:** Inverter um array
- **Atividade 3:** Gerar uma lista de números pares

---

## 🚀 Tecnologias Utilizadas

- **JavaScript (ES6+)**
- **Node.js**

---

## 📜 Como Usar

1. Clone este repositório:
   ```sh
   git clone https://github.com/rogeriobgregorio/estudos-nodejs.git
   ```
2. Acesse a pasta do repositório:
   ```sh
   cd estudos-nodejs
   ```
3. Navegue até a pasta da atividade desejada e siga as instruções no **README** dessa pasta específica.

---

## 📚 Pré-requisitos

Antes de começar, certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.
