# Atividades de Funções e Arrays em JavaScript

Esta pasta contém três atividades que envolvem operações matemáticas, manipulação de arrays e loops em JavaScript. Cada atividade é modularizada em arquivos separados e utiliza a importação e exportação de funções.

## 📌 Atividades

### **Atividade 1: Operações Matemáticas com Módulos**
Criar quatro funções em arquivos separados para realizar operações matemáticas básicas: **somar, subtrair, multiplicar e dividir**. O arquivo principal importa essas funções e executa a operação com base em um sinal pré-definido.

#### **📁 Estrutura de Arquivos**
```
📂 projeto
│-- 📄 somar.js
│-- 📄 subtrair.js
│-- 📄 multiplicar.js
│-- 📄 dividir.js
│-- 📄 index.js (arquivo principal)
```

#### **📜 Como Usar**
1. Defina a operação desejada no arquivo `index.js` alterando a variável `sinal` para `+`, `-`, `*` ou `/`.
2. Execute o código com Node.js:
   ```sh
   node index.js
   ```

---

### **Atividade 2: Inverter um Array**
Criar uma função que recebe um array de números e retorna o array invertido.

#### **📁 Estrutura de Arquivos**
```
📂 projeto
│-- 📄 inverterArray.js
│-- 📄 index.js (arquivo principal)
```

#### **📜 Como Usar**
1. No arquivo `index.js`, altere o array de números conforme desejado.
2. Execute o código:
   ```sh
   node index.js
   ```

---

### **Atividade 3: Gerar uma Lista de Números Pares**
Criar uma função que gera um array contendo os primeiros **N** números pares.

#### **📁 Estrutura de Arquivos**
```
📂 projeto
│-- 📄 gerarPares.js
│-- 📄 index.js (arquivo principal)
```

#### **📜 Como Usar**
1. No arquivo `index.js`, altere a variável `N` para definir quantos números pares deseja gerar.
2. Execute o código:
   ```sh
   node index.js
   ```
